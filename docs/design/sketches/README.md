# UI sketches

Drop mockups here — PNG/JPG/WebP render for AI review; export SVG sketches as PNG first.
Naming: `m<major>-<minor>-<topic>-v<n>.png` (e.g. `m5-4-settings-v1.png`).
Reference them from the matching decision record, e.g. in
`docs/design/milestone-5.4-client-settings.md`:

    ![Settings sketch](sketches/m5-4-settings-v1.png)

The empty `.gdignore` file keeps this folder out of Godot's import/export pipeline
(sketches are design material, not game assets).
