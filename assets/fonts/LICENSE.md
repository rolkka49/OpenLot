# Bundled fonts — licence and provenance
Every font file in this directory is dedicated to the **public domain** under the
**CC0 1.0 Universal** licence by its author, **GGBotNet** — the whole pool at
<https://github.com/ggbotnet/fonts-cc0> (see that repository's `LICENSE`).

CC0 means: no conditions, no attribution required. The credit below is recorded anyway so
the provenance of every binary in this repo is traceable, and so a font can never be added
here without its source being written down (the `FontServiceSelfTest` guard pins that:
every `*.ttf` in this folder must be listed below).

One licence class for every asset here is a deliberate decision (§5.4's font pre-slice):
no OFL/MIT mixing, no per-file attribution obligations to track.

## Adding more

More CC0 faces can be dropped into `user://fonts/` at runtime (they appear in the settings
list as *Custom*) without touching this repo. A future §18 font pack installs into that same
directory, so no code change is needed for it either.
